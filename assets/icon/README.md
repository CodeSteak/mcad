# App-Symbol

- `cad.svg` – Quelle (ab 64 px), `cad-small.svg` – kleine Variante mit dickeren Linien (16–48 px).
- `png/` – gerenderte Größen 16–512 px (transparent), erzeugt mit Chromium aus den SVGs.
- Verwendet in `crates/cad-app/icons` (Tauri), `web/public/favicon.svg` und im Arch-Paket
  (hicolor-Icons, Desktop-Datei).

Farben: Teal-Verlauf `#17a38b` → `#0c6b60`, Würfel in hellem Teal, Anker in Palettenorange
`#dc813b`.
