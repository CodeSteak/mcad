UI redesign – concept

Draft for discussion, as of 2026-10-24. Applies equally to browser and Tauri. No new features, only order, weighting and uniform controls. Questions for you on the last page.

Decision (2026-10-24): all proposals (option A in each case) accepted. Accent colour not blue, but teal/emerald (e.g. light #0f766e, dark #3cc4a8; exact values after contrast check). The drafts below still show the old blue.

1. Findings

  1. Header bar: 10+ equally weighted text buttons; „Zuletzt“ (Recent) / „Beispiele“ (Examples) as grey labels with wide drop-down lists; three separate export buttons; at 1440 px „Einstellungen“ (Settings) is cut off.
  2. Three button sizes side by side (header bar 28 px, file bar 22 px, part export 18 px), different borders and spacing.
  3. File bar in the editor: „+ Datei, Datei laden, Hauptdatei, ×, Ordner…, ZIP laden…, ZIP ↓“ (+ File, Load file, Main file, ×, Folder…, Load ZIP…, ZIP ↓) – seven small buttons, sometimes next to, sometimes below the tabs.
  4. Two info rows above the view („Datei …“ (File …), „Bauteile … STL 3MF STEP … Alle: ZIP …“ (Parts … STL 3MF STEP … All: ZIP …)) cost height and mix display with export.
  5. View bar: views, grid checkbox and modes (section, colours, sketch) mixed; wraps, floats right-aligned; sub-bars (section, sketch) appear in different places with their own width.
  6. Sketch tools only as text, without groups; „Fertig“ (Done) looks like any other tool.
  7. Side panel only for colours; measuring would have no room.

6. Scope and verification

  • Shared building blocks Button, IconButton, Segmented, Menu, Toolbar in web/src/app/ui/; move all bars onto them. No function is dropped, everything stays reachable by keyboard.
  • Playwright selectors via roles/names (aria-label instead of button text); existing scenarios stay green; image comparison light/dark at 1280, 1440 and 1920 px, no wrapping and no clipping.
  • Test report with before/after images per area.
