# Model catalogues

[`everyday-models.pdf`](everyday-models.pdf) (HTML: [`everyday-models.html`](everyday-models.html), images in `img/`): catalogue of the example models from [`tests/models/everyday/`](../../tests/models/everyday/README.md), one page per model (two for assemblies) with description, rendering, key data, parameters and language features – generated with `CAD=target/release/mcad MCAD_IPC_DIR=/tmp/cadkat node tools/report/katalog.mjs` (measures everything with the CLI, needs ImageMagick; `--reuse` uses the measurements from `reports/tmp/katalog/`), then `node tools/report/print-pdf.mjs docs/models/everyday-models.html docs/models/everyday-models.pdf "Everyday models – catalogue"`.
