1 Scope

This report covers the four lower layers of the application (the UI is not part of this report):

  • Kernel: SMLib/SM_API (NVIDIA usd-brep @ c9c5979) behind a C++ facade with a flat C ABI (handles, error codes, face tags for provenance), linked natively and as Emscripten Wasm (smlib.wasm); Rust binding kernel-smlib. Operations: primitives, transformations, booleans, fillet/chamfer, extrusion (with twist/scale), revolve, loft, sweep, NURBS surface, thicken, shell, edge/face queries, classification, tessellation, mass properties.
  • Language: OpenSCAD dialect (cad-syntax, cad-eval): variables, functions, modules, children(), for/if/let/each, list comprehensions, echo/assert, modifiers, 2D/3D primitives, extrusions; plus the extensions from the spec: grids (grid), anchors, named instances, box() between grid points, fillets/chamfers with zones, loft, sweep, handles.
  • Engine: cad-engine evaluates the geometry tree incrementally with a cache (content-based keys), maps faces and edges to source lines, selects edges via zones and exports STL/3MF; cad-session provides the protocol for the worker and the CLI.
  • CLI: cad check | eval | inspect | render | export with --json; render uses the software rasterizer cad-render.

7 Known limitations

  • SMLib booleans are unreliable in special configurations. The facade detects wrong results by sampling, not completely: an error between all probe points goes undetected. The check uses SMLib's point classification, which itself is wrong for rotated spline bodies (knauf_mirror); if no variant passes, SMLib's own result is therefore kept. In the shift fallback, the second operand deviates by up to 10⁻⁴ of the model size. The check costs time: cad export of all 41 examples, measured during the fix, 13.7 s → 18.9 s (+38 %), most for unions of many parts (07_crown_ring ×2.1) and for knauf_mirror (×1.9, fallbacks).
  • Open results: if bodies touch along an edge, the union in SMLib is not a closed body; cad then reports volume 0 (winkel_anker; the STL is fine). knauf_mirror: the rotated spline body minus the hole is open, torus and pin are missing from the result, the fillet at the hole fails (SM_ERR) – all as before this round, still open.
  • Tessellation of freeform surfaces: the refinement sets a global maximum edge length, so planar faces of the same body also become finer (12_linear_extrude_twist: 15 730 triangles, OpenSCAD 452).
  • Twist extrusion is a cubic loft approximation through sections every 7.5°. Circular profiles with non-uniform scale and scale = 0 (apex) are not supported.
  • OpenSCAD facets, we compute exactly: volumes of round parts deviate systematically by 0.01–0.3 %; with twist, OpenSCAD itself is off by ~1 % (section 4).
  • Determinism: rand() is replaced with a fixed, process-wide implementation. Memory errors in SMLib make results depend on the heap: the shell pre-check only covers planar, opposite walls; walls that barely fit (10 mm cube, t = 4.99) already show invalid reads under valgrind. Only the upstream fixes (tangency-labs/smlib 93efd6d, af8db37) or solidcore will resolve this.
  • cad render is a software rasterizer (orthographic, Lambert, 2×2 supersampling) without shadows or perspective. Per-pixel transparency needs memory proportional to the number of layers.
  • Not part of this report: browser UI, STEP export, switch to solidcore (M8).
