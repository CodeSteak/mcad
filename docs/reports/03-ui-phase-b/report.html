1 Umfang

Phase B ergänzt die Browser-UI um das Bearbeiten in der 3D-Ansicht. Der Code bleibt die einzige Quelle: Griffe ändern Literale oder schreiben Rasterreferenzen, die Parameterleiste ändert nur die Vorschau.

  • Griffe der Zeile unter dem Cursor, nur bei Literal oder Variable mit Literal; berechnete Werte werden als gesperrter Griff (grauer Ring) gezeigt. Arten: cube-/square-Ecke, box-/rect-Eckpunkte, Radius (sphere, circle, cylinder, torus), Höhe (cylinder, linear_extrude), cylinder zwischen zwei Punkten, translate-Ziel (Pfeil alt → neu, Griff am Ziel), Drehring pro Achse (rotate), Skalierung an der Hüllenecke, Rasterebenen mit Literal (Griff auf einer Kante der Rasterbox, Ziehen entlang der Achse), Punktvariablen, polygon-/spline-Punkte, Zonenmittelpunkt über translate. Farben: Literal orange, Standardwert eines Modulparameters violett, reine Referenz türkis, gesperrt grau.
  • Ziehen: DragStart → Drag (höchstens eine Nachricht in Flug, letzte Position gewinnt) → Edits → Editor wendet sie als Live-Änderung an und sendet den Quelltext sofort; die Engine tesselliert grob, nach DragEnd fein. Ein Ziehvorgang ist ein Undo-Schritt (Live-Änderungen ohne Verlauf, am Ende als ein isoliertes Ereignis). Esc bricht ab.
  • Snappen im Bildschirmraum (Fangradius einstellbar, Standard 14 px) auf Rasterpunkte des Moduls und sichtbare Anker (SnapTargets), Ziel hervorgehoben und beschriftet; geschrieben wird die Referenz. 1D-Griffe (Höhe, Radius, Ebene) snappen auf Rasterebenen derselben Achse und schreiben g.name (neu in cad-eval). Alt: kein Snap, Zahlen gerundet auf die Schrittweite (Einstellungen, Standard 1 mm / 15°).
  • Parameterleiste neben der Ansicht im Modulkontext: Zahl (Eingabefeld + Schieberegler), Bool (Schalter), Vektor (drei Felder); Reset pro Parameter, Markierung geänderter Werte, „Alle zurücksetzen“, Werte pro Modul bis Sitzungsende, „Als Standard übernehmen“ (SetDefault). Vorschau über SetContext { overrides }.
  • Inline-Regler für Zahl- und Bool-Literale von Zuweisungen am Zeilenende (Schieberegler, Schalter); ein Schieberegler-Zug ist ein Undo-Schritt.
  • Strg+Klick auf einen Raster- oder Ankerausdruck springt zur Deklaration.

Änderungen an Rust-Crates: cad-eval (gesperrte Griffe als locked_handles, SnapRef::Plane mit Prüfung, dass der Griff nach dem Schreiben exakt auf der Ebene liegt und die Ebene an der Stelle sichtbar ist), cad-session (Drag antwortet immer, SetDragOptions, Szene mit locked_handles), Protokoll-Typen neu erzeugt.

6 Bekannte Grenzen und Abweichungen

  • Sprung zur Rasterdeklaration mit Strg+Klick statt einfachem Klick: ein einfacher Klick muss weiter den Cursor setzen, sonst wären Rasterausdrücke nicht editierbar. Referenzen eines Moduls kennt die UI erst im Modulkontext (Cursor im Modul).
  • Ohne Alt wird gesnappt, wenn ein Ziel im Fangradius liegt, sonst werden Zahlen geschrieben (gerundet). Ein Griff, der nur aus Referenzen besteht (z. B. box(g[…], g[…])), wird ohne Alt nie zu Zahlen; er wechselt nur zwischen Zielen.
  • Snap von 1D-Griffen nur auf Ebenen, auf denen der Griff nach dem Schreiben von g.name exakt landet (gleicher Ursprung und Maßstab entlang der Achse). Unter einem verschobenen Teilbaum oder bei center = true/d = (Faktor 2) gibt es daher keine Ebenen-Ziele; geschrieben würde sonst ein Ausdruck wie g.deckel - 5, der den Griff sperrt.
  • Punktgriffe werden in der Ebene durch den Griff senkrecht zur Blickrichtung gezogen (2D-Punkte in ihrer xy-Ebene); entlang der Blickrichtung ändert sich nichts. Für eine bestimmte Achse hilft eine Standardansicht.
  • Undo-Gruppe: am Ende des Ziehens wird die Gesamtänderung einmal zurückgenommen und als ein Verlaufseintrag wieder angewendet; dabei entsteht eine zusätzliche Neuauswertung aus dem Cache.
  • Inline-Regler erscheinen nur bei Zuweisungen mit Zahl- oder Bool-Literal (Spec, Werttypen); der Bereich richtet sich nach dem Wert beim Start des Ziehens (0 … 2 × Wert, mindestens 10).
  • Parameter ohne Standardwert werden beim Reset auf 0 / false / [0, 0, 0] gesetzt (Spec-Tabelle); Zeichenketten und Listen sind nur lesbar.
  • Die Messwerte stammen aus headless Chromium mit SwiftShader.
