Scope

The CLI cad is extended so that an agent (e.g. Claude Code) can develop and check models entirely without the UI – alone or while a human edits the same files in the UI. New:

Command/optionPurpose
cad outlineOverview of a project in one call
render --viewsContact sheet with labelled tiles at the same scale
render --azimuth/--elevation/--zoom/--target/--fit/--perspectiveFree camera
render --part/--line (repeatable)/--node/--onlySelection, combinable with --module, -D
render --show grids,anchors,handles,edges,labels,bbox,dimsOverlays
render --section/--section-plane/--section-flip, --xraySection with filled cap, X-ray
cad measureDistances (anchors, grid points, coordinates), bounding box, volume, area, collisions, part clearance
cad watchRe-evaluate on file change, one JSON line per run, optional image
cad setChange a default value or literal through the engine, checked, atomic, --dry-run
cad DATEI.scad, cadUI entry point reserved (exit 2 with message), help without arguments

Every command has --json with a fixed, versioned schema (schema_version 1, complete in the header of crates/cad-cli/src/main.rs, short form in the skill .claude/skills/cad-cli/SKILL.md) and the existing exit codes (0 ok, 1 model error, 2 invocation, 3 kernel). Recommended workflow for agents: outline → edit → check → render --views all --show grids,anchors → inspect/measure → export. cad-render draws labels with an embedded bitmap font (DejaVu Sans Mono, generated by tools/font/gen-font.py), without a new runtime dependency.

5 cad render: section and X-ray

Section: --section x=WERT|y=WERT|z=WERT, --section-plane px,py,pz,nx,ny,nz, --section-flip. Convention (the same for the later UI): plane through p with normal n; the half that n points into is removed, (q − p)·n ≤ 0 remains. z=10 means p = (0,0,10), n = +z; --section-flip reverses n. The section face is drawn as a hatched cap in its own color (hatching alternates per body), the section contour as a line.

Method: clipping in the renderer with a cap, no kernel boolean. The triangles are clipped geometrically at the plane (Sutherland–Hodgman per triangle, edges likewise). The cap follows the GPU stencil principle: for each sample, the number of times the view ray crosses the surface of a body up to the plane is counted (top-left rule, so shared edges count exactly once); if the count is odd, the plane point lies inside the body and the cap is written at plane depth. Reasons: (1) the UI will use the same method with GPU clipping and a stencil cap, so images and convention match; (2) it needs no kernel work – a boolean with a half-space quickly costs seconds for filleted bodies and can fail, clipping costs a few ms and always succeeds; (3) it works for any plane, also for views of several parts. It requires closed meshes; the tessellation of the B-rep bodies is closed. Open surfaces (surface) and transparent bodies get no cap.

6 cad measure

--between A B with anchors (k.ecke, k[2].ecke, in module context ecke), grid points of the context module (g[a,b,c], entries may also be numbers or _) and coordinates [x,y,z]: distance and difference vector. --bounds/--volume/--area ZIEL with all, part:NAME, line:N, node:I. --interference: pairwise intersection volume of all parts, exact via the kernel (boolean intersection of the B-rep, bounding boxes tested first); collision from --tolerance (default 0.001 mm³). --clearance A B: smallest distance between two parts as the exact triangle–triangle distance of their tessellations (BVH, tolerance --mesh-tol 0.01 mm, accuracy ± 2·0.01 mm); if the parts intersect, the distance is 0 and collision: true.

Expected values, spec example gehaeuse: k.ecke = [60, 30, 20], k.oben = [0, 0, 20] → √(60² + 30²) = 67.082 mm; in the module g[links,vorne,boden] → g[rechts,hinten,deckel] = √(40² + 30² + 20²) = 53.852 mm; volume k = 60·30·20 − 54·30·17 = 8460 mm³. kollision.scad: a and b overlap by 2 × 10 × 10 = 200 mm³, c is 5 mm next to b.

7 cad set

Decision: no persistent cache between calls. The second call is as fast as the first (no cache); a call takes up to 1.10 s – for variabler_radius at the 1 s limit, almost all of it kernel time (fillets) and tessellation. A file cache of the kernel results would be costly: the results are handles to SMLib objects in the memory of the native library; a cache would have to serialize and re-read the B-rep (together with the provenance of faces and edges), which itself costs kernel time. Instead cad watch: the same session persists, the engine cache holds all node results; a run after a change costs only the changed nodes (table in section 9: 30 ms for a change without effect on geometry, 947 ms when two filleted bodies are rebuilt). The skill recommends cad watch for loops with many small steps.

Step 1: write the draft

Source code
// Fallstudie Bericht 8: Wandhalter für eine Stange, nur mit der CLI entwickelt.
// Grundplatte an der Wand (y = 0), Ausleger mit Bohrung für die Stange, zwei Schraublöcher.
module halter(b = 40, t = 5, h = 50, a = 30, d = 20, spiel = 0) {
    grid g {
        x: links = 0, loch_l = 10, mitte = b / 2, loch_r = b - 10, rechts = b;
        y: wand = 0, platte = t, achse = t + a, vorn = t + a + d / 2 + t;
        z: unten = 0, loch = 10, arm = h - d - 2 * t, achse_z = h - t - d / 2, oben = h;
    }
    difference() {
        union() {
            box(g[links, wand, unten], g[rechts, platte, oben]);
            box(g[links, platte, arm], g[rechts, vorn, oben]);
        }
        cylinder(g[-1, achse, achse_z], g[b + 1, achse, achse_z], r = (d + spiel) / 2);
        for (x = [g.loch_l, g.loch_r])
            cylinder(g[x, -1, loch], g[x, t + 1, loch], r = 2.25);
    }
    anchor stange = g[links, achse, achse_z], dir = [1, 0, 0];
    anchor schraube = g[loch_l, wand, loch], dir = [0, -1, 0];
}

module stange(l = 60, d = 20) cylinder(h = l, r = d / 2);

13 Limitations

  • Section caps require closed meshes; open surfaces (surface without thicken) and transparent bodies get no cap. The cap is flat and single-colored (hatching alternates per body), no distinction by material.
  • --clearance measures on the tessellation (accuracy ± 2·--mesh-tol), --interference exactly via the kernel; parts whose bounding boxes do not overlap are counted as collision-free without the kernel.
  • Grid points are labelled up to 48 points per grid, above that only the planes (note in notes); overlapped labels are dropped.
  • outline evaluates each module with its default values; modules with required parameters without a default may then show no grids (errors_with_defaults).
  • watch re-reads all project files on every change; changes within the debounce time (--debounce, 60 ms) are merged into one run.
  • No persistent cache between calls (section 10).
