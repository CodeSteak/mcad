1 Task and result

From step 3 of plan 17: SVG import (subset, 17.5) and text with bundled free fonts (17.4). The custom stencil font "cad stencil mono" is not part of this (it needs stroke from step 2); the name is reserved as the future default font; until then JetBrains Mono is the default font (hint for font = "cad stencil mono").

  • text(t, size, font, halign, valign, spacing, direction, language, script): exact outlines (TrueType quadratic, CFF cubic), kerning and ligatures via rustybuzz, holes by nonzero, color() as usual. Bounding box and area against OpenSCAD 2021.01 with the same font files: bounding box ≤ 0.004 mm, area ≤ 0.28 % (OpenSCAD samples the curves).
  • import("….svg", id, scale, dpi = 96, center): paths (all commands), rectangles with rounding, circles and ellipses exact, polygons, groups and nested svg with transform, units, fill-rule, display:none; everything else with a warning and the SVG line.
  • Files relative to the including file (CLI: file system; browser: project files; desktop: reads and writes them); changed SVGs change the cache key, cad watch follows them, and so does the UI scene (T02).
  • Required character set with umlauts, ß/ẞ and punctuation in all bundled fonts (test); gaps (Allerta Stencil only) are filled from JetBrains Mono with a warning.
  • Along the way: color regions of models that are only unions of their color nodes, without a Boolean with the whole (multicolor text: seconds instead of abort by the watchdog).
  • Found with the alphabet chart: SMLib united disjoint glyph parts wrongly (Allerta "c": one piece twice, once reversed; volume 2.0 instead of 7.3 mm³, "a" in "abcd" disappeared, without a message). The facade now unites bodies with disjoint bounding boxes without an SMLib Boolean (disjoint_union: both shells into one B-rep); regression test text_volume_is_area_times_height.

// Purpose: sign with relief text (plan 17.4, report 16) – base plate with a rim, raised text in
// two fonts – multicolor (3MF with one filament per color).
// Fonts: bundled are JetBrains Mono (default), Inter and Allerta Stencil, each with
// a style (`"Inter:style=Bold"`); custom fonts with `font = "datei.ttf"` (file in the project).
// `size` as in OpenSCAD: cap height about `size`.

breite = 100;
hoehe = 44;
dicke = 3;
r = 5;          // corner radius
rand = 2;       // width of the rim
relief = 1.2;   // height of text and rim

module platte(b, h, r) sketch {
    start([r, 0]);
    line(to = [b - r, 0]);
    arc(center = [b - r, r], angle = 90);
    line(to = [b, h - r]);
    arc(center = [b - r, h - r], angle = 90);
    line(to = [r, h]);
    arc(center = [r, h - r], angle = 90);
    line(to = [0, r]);
    arc(center = [r, r], angle = 90);
}

color("white") linear_extrude(dicke) platte(breite, hoehe, r);

// rim
color("blue") translate([0, 0, dicke]) linear_extrude(relief) difference() {
    platte(breite, hoehe, r);
    translate([rand, rand]) platte(breite - 2 * rand, hoehe - 2 * rand, r - rand);
}

// title and subtitle raised
color("red") translate([breite / 2, 26, dicke])
    linear_extrude(relief) text("Werkstatt", size = 11, font = "Inter:style=Bold", halign = "center", valign = "center");
color("black") translate([breite / 2, 9, dicke])

10 Limitations

  • The custom stencil font is missing (step 3, after stroke); Allerta Stencil lacks 20 characters of the required character set (taken from JetBrains Mono, not stenciled).
  • Kernel time: many glyphs on a common face are expensive (the union in SMLib grows superlinearly: 9 glyphs ≈ 1.5 s, 28 ≈ 9 s native); in the browser it takes about 1.3 to 1.8 times as long; a single kernel call over 15 s triggers the watchdog.
  • Fill rules assume non-intersecting contours within one element (fonts with overlapping contours, e.g. some variable fonts, and self-intersecting SVG paths are not resolved). Variable fonts only in the default instance.
  • SVG: no text, no use clones, no CSS classes, no strokes as areas, no masks/clip paths; percent and em lengths are treated like plain numbers.
  • File names must appear as strings in the project (a name composed at run time is not loaded).
  • Found with the logo: the facade computed unions of extruded sketch arcs over 90° wrongly (sketches step 1); fixed in step 2 (profile::split_arcs), the interim workaround in the import was removed.
  • STEP: the writer now writes extrusions of elliptical arcs as an extrusion of an ELLIPSE (OpenCASCADE had integrated the rational B-spline wrongly by 3.6·10−3). Open: OpenCASCADE measures the extrusion of the quadratic Q/T wave from welle.svg 3 % too small (kernel 652.25 mm², analytical 652.19 mm²) – svg_logo.scad therefore takes only the ellipse and the arc from welle.svg; the wave itself is shown in 5.1.
  • Default alignment of vertical text as in OpenSCAD (shaper offset); valign by the actual glyph bounding box (OpenSCAD: rasterized FreeType metrics, ≤ 0.005 mm).
