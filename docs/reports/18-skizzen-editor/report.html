1 Auftrag und Ergebnis

Plan 17.6: Werkzeuge in der Ansicht, Zeichnen in der Skizzenebene mit Raster, Snap mit Anzeige, jede Aktion schreibt Code in den sketch-Block am Cursor oder legt einen an, Undo wie beim Ziehen, Bearbeiten über Griffe, Segment löschen; der Code bleibt die einzige Quelle. Umgesetzt:

  • Zeichenmodus (Schalter „Skizze“): Kamera senkrecht auf die Skizzenebene – auch unter Transformationen, im rotate_extrude (xz-Ebene) und im zentrierten linear_extrude (Boden); Schrittraster, Rasterlinien und -punkte des Moduls oder der Skizze in der Ebene; Werkzeugleiste, Statuszeile, Esc beendet.
  • Werkzeuge Linie (Kette, Klick auf den Anfang schließt), Bogen durch drei Punkte, Bogen um einen Mittelpunkt, tangentialer Bogen, Bézier (kubisch), Rechteck, Kreis, Ecke runden (corner(r)), Schließen, Löschen, Auswahl. Jede Aktion ist ein Text-Edit in der Sprache, die es schon gibt, und ein Undo-Schritt.
  • Snap auf Rasterpunkte und Anker (Referenzen wie g[b, u], k.ecke), Anfang, Ecken, End-, Mittel- und Schnittpunkte, Bogenmitten, tangential (line(length = …)), horizontal/vertikal, Rasterlinien ([g.b, 40]), Schrittweite; Alt = frei mit Schrittweite. Die Markierung zeigt die Art, die Beschriftung den Text, der geschrieben würde.
  • Bearbeiten: mit „Auswahl“ die Griffe aller Segmente (bestehende Griff-Logik: Literal ändern, Rasterreferenz umschreiben), Klick auf ein Segment setzt den Cursor, Entf löscht.
  • Logik in Rust: Skizze und Einfügestelle, Zeichenzustand, Snap, Code, Vorschau, Löschen, Ecken, Raster, Ebene und Strahlschnitt in cad-eval/cad-session; die UI reicht Maus und Tasten weiter und wendet die Antwort an. Dasselbe über WorkerTransport (Wasm) und TauriTransport (nativer Engine-Prozess).

2 Entscheidungen

FrageEntscheidung
Wohin der Code gehtSkizze = die sketch-Anweisung, die den Cursor enthält oder auf seiner Zeile beginnt. Einfügen nach der Anweisung der Cursorzeile (bzw. der letzten davor), im innersten hole-Block; auf der sketch {-Zeile ans Ende; leere Blöcke werden aufgeklappt. Ohne Skizze: neuer sketch { … }-Block am Ende des Kontextmoduls bzw. der Datei. Nach jeder Aktion steht der Cursor hinter dem neuen Code.
Aktueller PunktAus der Auswertung: SketchInfo::steps hält jede Segmentanweisung in Auswertungsreihenfolge mit dem Zustand danach (Kontur, Anfang, Punkt, Richtung; Geometrie vor corner()) – auch für Schleifen und Modulaufrufe im Block. Linie, Bögen, Bézier setzen die offene Kontur fort, wenn ihr erster Punkt deren Ende ist; sonst start(p). Eine neue Kontur mitten in einer weiterlaufenden kommt hinter deren Ende.
Zustand der WerkzeugeDie Engine ist ohne Zustand: die gewählten Punkte (Position, Text, Art) gehen mit jeder Anfrage hin und mit der Antwort zurück. Höchstens eine Anfrage unterwegs, die letzte Mausposition gewinnt, Klicks in Reihenfolge.
UndoEine Transaktion je Aktion mit isolateHistory (auch start + erste Linie zusammen); die Quelle geht sofort an die Engine, die Nachrichten in Reihenfolge bearbeitet – die nächste Anfrage sieht den neuen Text. Strg+Z wirkt auch mit dem Fokus in der Ansicht.
Referenzen statt ZahlenRasterpunkte und Anker schreiben ihre Referenz; ein Rechteck aus zwei Rasterpunkten bekommt auch die anderen Ecken als Rasterpunkte. Freie Punkte: Zahlen auf die Schrittweite gerundet; exakte Punkte (End-, Schnittpunkte …): kürzeste Zahl mit 6 Stellen. 2D-Punkte schreiben g[a, b] (auch beim Griff-Snap, statt g[a, b, _]).
Ebenesketch_frame: Knotensystem, im rotate_extrude die xz-Ebene, beim zentrierten linear_extrude der Boden – für Editor, Griffe (Handle.frame) und Darstellung (OpInfo::Sketch.plane).
Griffe und WerkzeugeZeichenwerkzeuge zeichnen auch auf bestehenden Punkten (dort keine Griffe, die den Klick abfangen); Griffe aller Segmente mit „Auswahl“.
ToleranzSnap-Radius in Pixeln (Einstellungen, 14 px) mal Pixelgröße am Treffpunkt des Strahls; die UI schickt nur Strahl, Pixelgröße und Radius.

4 Werkzeuge

Jedes Szenario zeichnet mit der Maus (Playwright, echte Zeigerereignisse) und prüft den geschriebenen Code wörtlich; links der Code nach der Aktion, rechts die Ansicht.

Z02 Linie

Ohne sketch-Block am Cursor legt die erste Aktion einen an (am Ende der Datei). Jeder Klick ist eine Aktion: start(…) und die erste Linie, dann line(to = …) je Punkt; der Klick auf den Anfang der Kontur schreibt close();. Freie Punkte werden auf die Schrittweite gerundet.

cube([30, 20, 2]);

sketch {
    start([0, 0]);
    line(to = [20, 0]);
    line(to = [20, 12]);
    line(to = [5, 12]);
    close();
}
  • neuer sketch-Block
  • 4 Aktionen
  • close() durch Klick auf den Anfang
  • keine Fehler

Z03 Rechteck auf Rasterpunkten

Snappen auf Rasterpunkte schreibt Referenzen. Beim Rechteck aus zwei Rasterpunkten werden auch die beiden anderen Ecken Rasterpunkte (g[c, u], g[b, v]): ändert sich eine Ebene, folgt das Rechteck.

grid g {
    x: a = 0, b = 10, c = 30, d = 40;
    y: u = 0, v = 15, w = 25;
}
linear_extrude(3) sketch {
    start(g[b, u]);
    line(to = g[c, u]);
    line(to = g[c, v]);
    line(to = g[b, v]);
    close();
}
  • Snap-Text g[b, u] sichtbar
  • Ecken als g[…]
  • Vorschau 1 Polylinie

Z04 Kreis

Mittelpunkt, dann ein Punkt auf dem Kreis: start(p); arc(center = c, angle = 360); close(); – eine eigene Kontur nach der offenen.

linear_extrude(2) sketch(closed = false) {
    start([0, 0]);
    line(to = [20, 0]);
    start([30, 6]);
    arc(center = [26, 6], angle = 360);
    close();
}
  • start/arc(center, angle = 360)/close

Z05 Bogen durch drei Punkte

Anfang (hier das Ende der Kontur, kein neues start), Punkt auf dem Bogen, Endpunkt: arc(through = q, to = p).

linear_extrude(2) sketch(closed = false) {
    start([0, 0]);
    line(to = [20, 0]);
    arc(through = [24, 4], to = [20, 8]);
}
  • arc(through = [24, 4], to = [20, 8])

Z06 Bogen um einen Mittelpunkt

Anfang, Mittelpunkt, Endwinkel: arc(center = c, angle = a); der Winkel rastet auf die Winkelschrittweite (15°), auf einem gesnappten Punkt entsteht arc(center = c, to = p).

linear_extrude(2) sketch(closed = false) {
    start([0, 0]);
    line(to = [20, 0]);
    arc(through = [24, 4], to = [20, 8]);
    arc(center = [16, 8], angle = 90);
}
  • arc(center = [16, 8], angle = 90)

Z07 Tangentialer Bogen

Ein Klick: der Bogen setzt die Richtung des letzten Segments fort, arc(to = p).

linear_extrude(2) sketch(closed = false) {
    start([0, 0]);
    line(to = [20, 0]);
    arc(through = [24, 4], to = [20, 8]);
    arc(center = [16, 8], angle = 90);
    arc(to = [10, 10]);
}
  • arc(to = [10, 10])

Z08 Bézier

Anfang, zwei Kontrollpunkte, Ende: kubische Kurve bezier(c1 = …, c2 = …, to = …).

linear_extrude(2) sketch(closed = false) {
    start([0, 0]);
    line(to = [20, 0]);
    bezier(c1 = [24, 0], c2 = [27, 5], to = [27, 10]);
}
  • bezier(c1 = [24, 0], c2 = [27, 5], to = [27, 10])

Z09 Ecke runden

Ecke wählen (nur Ecken zwischen zwei Segmenten snappen), dann den Radius als Abstand zur Ecke: corner(r = …) nach dem Segment, das dort endet; an einer schon gerundeten Ecke ändert sich der Radius.

linear_extrude(2) sketch {
    start([0, 0]);
    line(to = [30, 0]);
    line(to = [30, 20]);
    corner(r = 4);
    line(to = [0, 20]);
    close();
}
  • corner(r = 4) nach line(to = [30, 20])

Z10 Schließen

„Schließen“ schreibt close(); für die offene Kontur am Cursor; der Fehler „Kontur nicht geschlossen“ verschwindet.

linear_extrude(2) sketch {
    start([0, 0]);
    line(to = [30, 0]);
    line(to = [30, 20]);
    close();
}
  • close(); eingefügt
  • keine Fehler

5 Snap

Z11 Snap-Arten

Reihenfolge: Rasterpunkte und Anker (Referenz), Anfang, Ecken, End-, Mittel-, Schnittpunkte und Bogenmitten (Zahlen); sonst tangential (schreibt line(length = …)), horizontal/vertikal zum vorigen Punkt und Rasterlinien ([g.b, 40]), sonst die Schrittweite. Alt: frei mit Schrittweite. Die Markierung zeigt die Art (Ring Punkt, Quadrat Raster, Raute Richtung, Kreuz Schritt).

grid g {
    x: a = 0, b = 10;
    y: u = 0;
}
linear_extrude(2) sketch(closed = false) {
    start([0, 5]);
    line(to = [20, 5]);
    line(to = [20, 25]);
    start([0, 25]);
    line(to = [30, 15]);
    line(length = 6);
}
  • Endpunkt → end: [20, 5]
  • Mitte → mid: [10, 5]
  • Schnittpunkt → intersection: [20, 18.3333]
  • Rasterpunkt → grid: g[b, u]
  • horizontal → horizontal: [42, 25]
  • Rasterlinie → grid_line: [g.b, -6]
  • Alt → step: [10, 0]
  • tangential → tangent: [35.6921, 13.1026]

6 Bearbeiten: Undo, Griffe, Löschen

Z12 Undo

Jede Aktion ist ein eigener Verlaufsschritt (auch start + erste Linie zusammen); Strg+Z/Strg+Umschalt+Z wirken auch mit dem Fokus in der Ansicht.

// nach zwei Aktionen
linear_extrude(2) sketch(closed = false) {
    start([0, 0]);
    line(to = [20, 0]);
    line(to = [20, 10]);
    line(to = [5, 10]);
}
// Strg+Z, Strg+Z, Strg+Umschalt+Z
linear_extrude(2) sketch(closed = false) {
    start([0, 0]);
    line(to = [20, 0]);
    line(to = [20, 10]);
}
  • Undo nimmt genau eine Aktion zurück
  • Redo stellt sie wieder her

Z13 Griff ziehen

Im Zeichenmodus zeigt die Ansicht die Griffe aller Segmente der Skizze. Ziehen nutzt die bestehende Griff-Logik: auf einem Rasterpunkt wird die Referenz umgeschrieben, Literale werden geändert (Alt: Zahlen).

grid g {
    x: a = 0, b = 10, c = 30;
    y: u = 0, v = 15;
}
linear_extrude(2) sketch {
    start(g[a, u]);
    line(to = g[c, u]);
    line(to = g[c, v]);
    close();
}
  • g[b, v] → g[c, v]

Z14 Segment löschen

Mit dem Werkzeug Auswahl setzt ein Klick auf ein Segment den Cursor in seine Zeile, Entf (oder „Löschen“) entfernt die Anweisung. Das einzige Segment einer Kontur nimmt die Kontur mit, ein corner() direkt danach ebenfalls.

linear_extrude(2) sketch {
    start([0, 0]);
    line(to = [30, 0]);
    line(to = [0, 20]);
    close();
}
  • line(to = [30, 20]) entfernt

7 Zeichenmodus, Ebenen, Thema

Z01 Zeichenmodus ein/aus

„Skizze“ in der Ansichtsleiste schaltet den Zeichenmodus ein: die Kamera blickt senkrecht auf die Ebene der Skizze am Cursor, das Raster g und die Schrittweite (1 mm, gröber beim Herauszoomen) liegen in der Ebene, die Statuszeile sagt, was das Werkzeug als Nächstes braucht. Esc beendet den Modus.

grid g {
    x: a = 0, b = 10, c = 30, d = 40;
    y: u = 0, v = 15, w = 25;
}
linear_extrude(3) sketch {
}
  • Blickrichtung z = -1.00000
  • Rasterlinien 7, Schrittraster 42

Z15 Skizze unter Transformation, rotate_extrude

Die Ebene der Skizze kommt von der Engine (OpInfo.Sketch.plane): unter Transformationen ihr Knotensystem, im rotate_extrude die xz-Ebene, in der das Profil im Körper liegt, beim zentrierten linear_extrude dessen Boden. Kamera, Raster, Snap und Griffe nutzen dieselbe Ebene; die Werte bleiben Koordinaten der Skizze.

translate([0, 0, 10]) rotate([90, 0, 0]) linear_extrude(3) sketch {
    start([0, 0]);
    line(to = [20, 0]);
    line(to = [20, 10]);
    line(to = [10, 15]);
    close();
}

rotate_extrude() sketch {
    start([10, 0]);
    line(to = [20, 0]);
    line(to = [20, 5]);
    line(to = [15, 8]);
    close();
}
  • Blick y = 1.00000
  • Snap-Punkt z = 20 (Welt)
  • rotate_extrude: Blick y = 1.00000

11 Grenzen

  • Nur die Hauptdatei: in einer anderen Projektdatei startet der Modus nicht; Skizzen aus eingebundenen Dateien sind kein Ziel.
  • Anweisungen in Schleifen oder Modulen werden weder gelöscht noch bekommt ihre Ecke ein corner() (Meldung). Der Zeichenzustand mitten in einer Schleife ist der nach ihrem letzten Durchlauf.
  • Snap nur auf die Skizze, sichtbare Raster und Anker – nicht auf Körperkanten oder andere Skizzen; horizontal/vertikal nur zum vorigen Punkt.
  • Bézier nur kubisch, kein Spline-Werkzeug; line(by = …) und length + angle entstehen nicht (außer tangential line(length = …)).
  • Eine neue Skizze ist eine bloße 2D-Skizze (zum Körper: z. B. linear_extrude davor schreiben).
  • Die Kamera behält „z oben“ der Bahnsteuerung: in gedrehten Ebenen steht die y-Achse der Skizze nicht unbedingt senkrecht auf dem Bildschirm. Mit einem Zeichenwerkzeug dreht die linke Maustaste die Kamera nicht (rechts verschieben, Rad zoomen, „Auswahl“ zum Drehen).
  • Tauri: T16 bedient die Ansicht mit synthetischen Zeigerereignissen.
