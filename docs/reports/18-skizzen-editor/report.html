1 Task and result

Plan 17.6: tools in the view, drawing in the sketch plane with a grid, snap with indicator, every action writes code into the sketch block at the cursor or creates one, undo as with dragging, editing via handles, deleting segments; the code remains the single source. Implemented:

  • Drawing mode (toggle "Sketch", German UI: „Skizze“): camera perpendicular to the sketch plane – also under transformations, in rotate_extrude (xz plane) and in centered linear_extrude (bottom face); step grid, grid lines and grid points of the module or the sketch in the plane; toolbar, status line, Esc exits.
  • Tools line (chain, a click on the start closes), arc through three points, arc around a center, tangent arc, Bézier (cubic), rectangle, circle, round corner (corner(r)), close, delete, select. Every action is a text edit in the existing language and one undo step.
  • Snap to grid points and anchors (references such as g[b, u], k.ecke), start, corners, end points, midpoints and intersections, arc midpoints, tangent (line(length = …)), horizontal/vertical, grid lines ([g.b, 40]), step size; Alt = free with step size. The marker shows the kind, the label shows the text that would be written.
  • Editing: with "Select" the handles of all segments (existing handle logic: change a literal, rewrite a grid reference), a click on a segment sets the cursor, Del deletes.
  • Logic in Rust: sketch and insertion point, drawing state, snap, code, preview, deletion, corners, grid, plane and ray intersection in cad-eval/cad-session; the UI forwards mouse and keys and applies the response. The same via WorkerTransport (Wasm) and TauriTransport (native engine process).

2 Decisions

QuestionDecision
Where the code goesSketch = the sketch statement that contains the cursor or starts on its line. Insertion after the statement on the cursor line (or the last one before it), in the innermost hole block; on the sketch { line at the end; empty blocks are expanded. Without a sketch: new sketch { … } block at the end of the context module or the file. After every action the cursor is placed after the new code.
Current pointFrom the evaluation: SketchInfo::steps holds every segment statement in evaluation order with the state after it (contour, start, point, direction; geometry before corner()) – also for loops and module calls in the block. Line, arcs and Bézier continue the open contour if their first point is its end; otherwise start(p). A new contour in the middle of a continuing one goes after its end.
Tool stateThe engine is stateless: the chosen points (position, text, kind) go out with every request and come back with the response. At most one request in flight, the last mouse position wins, clicks in order.
UndoOne transaction per action with isolateHistory (also start + first line together); the source goes to the engine immediately, which processes messages in order – the next request sees the new text. Ctrl+Z also works with focus in the view.
References instead of numbersGrid points and anchors write their reference; a rectangle from two grid points also gets the other corners as grid points. Free points: numbers rounded to the step size; exact points (end points, intersections …): shortest number with 6 digits. 2D points write g[a, b] (also with handle snap, instead of g[a, b, _]).
Planesketch_frame: node coordinate system, in rotate_extrude the xz plane, in centered linear_extrude the bottom face – for editor, handles (Handle.frame) and rendering (OpInfo::Sketch.plane).
Handles and toolsDrawing tools also draw on existing points (no handles there to catch the click); handles of all segments with "Select".
ToleranceSnap radius in pixels (settings, 14 px) times pixel size at the ray hit point; the UI sends only ray, pixel size and radius.

Mouse moved     → Sketch { cursor, tool, points, ray, pixel, snap_px, free }        (≤ 1 in flight)
                 ← Sketch { plane, snap {point, text, kind, label}, guides, preview, prompt }

                 ← points (point stored)  or  edits + select (action done)

4 Tools

Each scenario draws with the mouse (Playwright, real pointer events) and checks the written code verbatim; left the code after the action, right the view.

Z02 Line

Without a sketch block at the cursor, the first action creates one (at the end of the file). Every click is an action: start(…) and the first line, then line(to = …) per point; a click on the start of the contour writes close();. Free points are rounded to the step size.

cube([30, 20, 2]);

sketch {
    start([0, 0]);
    line(to = [20, 0]);
    line(to = [20, 12]);
    line(to = [5, 12]);
    close();
}
  • new sketch block
  • 4 actions
  • close() by clicking on the start
  • no errors

Z03 Rectangle on grid points

Snapping to grid points writes references. For a rectangle from two grid points, the other two corners also become grid points (g[c, u], g[b, v]): if a grid level changes, the rectangle follows.

grid g {
    x: a = 0, b = 10, c = 30, d = 40;
    y: u = 0, v = 15, w = 25;
}
linear_extrude(3) sketch {
    start(g[b, u]);
    line(to = g[c, u]);
    line(to = g[c, v]);
    line(to = g[b, v]);
    close();
}
  • snap text g[b, u] visible
  • corners as g[…]
  • preview 1 polyline

Z04 Circle

Center, then a point on the circle: start(p); arc(center = c, angle = 360); close(); – a separate contour after the open one.

linear_extrude(2) sketch(closed = false) {
    start([0, 0]);
    line(to = [20, 0]);
    start([30, 6]);
    arc(center = [26, 6], angle = 360);
    close();
}
  • start/arc(center, angle = 360)/close

Z05 Arc through three points

Start (here the end of the contour, no new start), point on the arc, end point: arc(through = q, to = p).

linear_extrude(2) sketch(closed = false) {
    start([0, 0]);
    line(to = [20, 0]);
    arc(through = [24, 4], to = [20, 8]);
}
  • arc(through = [24, 4], to = [20, 8])

Z06 Arc around a center

Start, center, end angle: arc(center = c, angle = a); the angle snaps to the angle step (15°), on a snapped point the result is arc(center = c, to = p).

linear_extrude(2) sketch(closed = false) {
    start([0, 0]);
    line(to = [20, 0]);
    arc(through = [24, 4], to = [20, 8]);
    arc(center = [16, 8], angle = 90);
}
  • arc(center = [16, 8], angle = 90)

Z07 Tangent arc

One click: the arc continues the direction of the last segment, arc(to = p).

linear_extrude(2) sketch(closed = false) {
    start([0, 0]);
    line(to = [20, 0]);
    arc(through = [24, 4], to = [20, 8]);
    arc(center = [16, 8], angle = 90);
    arc(to = [10, 10]);
}
  • arc(to = [10, 10])

Z08 Bézier

Start, two control points, end: cubic curve bezier(c1 = …, c2 = …, to = …).

linear_extrude(2) sketch(closed = false) {
    start([0, 0]);
    line(to = [20, 0]);
    bezier(c1 = [24, 0], c2 = [27, 5], to = [27, 10]);
}
  • bezier(c1 = [24, 0], c2 = [27, 5], to = [27, 10])

Z09 Round corner

Pick a corner (only corners between two segments snap), then the radius as the distance to the corner: corner(r = …) after the segment that ends there; on an already rounded corner the radius changes.

linear_extrude(2) sketch {
    start([0, 0]);
    line(to = [30, 0]);
    line(to = [30, 20]);
    corner(r = 4);
    line(to = [0, 20]);
    close();
}
  • corner(r = 4) after line(to = [30, 20])

Z10 Close

"Close" writes close(); for the open contour at the cursor; the error "contour not closed" (German: „Kontur nicht geschlossen“) disappears.

linear_extrude(2) sketch {
    start([0, 0]);
    line(to = [30, 0]);
    line(to = [30, 20]);
    close();
}
  • close(); inserted
  • no errors

5 Snap

Z11 Snap kinds

Order: grid points and anchors (reference), start, corners, end points, midpoints, intersections and arc midpoints (numbers); otherwise tangent (writes line(length = …)), horizontal/vertical to the previous point and grid lines ([g.b, 40]), otherwise the step size. Alt: free with step size. The marker shows the kind (ring point, square grid, diamond direction, cross step).

grid g {
    x: a = 0, b = 10;
    y: u = 0;
}
linear_extrude(2) sketch(closed = false) {
    start([0, 5]);
    line(to = [20, 5]);
    line(to = [20, 25]);
    start([0, 25]);
    line(to = [30, 15]);
    line(length = 6);
}
  • end point → end: [20, 5]
  • midpoint → mid: [10, 5]
  • intersection → intersection: [20, 18.3333]
  • grid point → grid: g[b, u]
  • horizontal → horizontal: [42, 25]
  • grid line → grid_line: [g.b, -6]
  • Alt → step: [10, 0]
  • tangent → tangent: [35.6921, 13.1026]

6 Editing: undo, handles, delete

Z12 Undo

Every action is a separate history step (also start + first line together); Ctrl+Z/Ctrl+Shift+Z also work with focus in the view.

// after two actions
linear_extrude(2) sketch(closed = false) {
    start([0, 0]);
    line(to = [20, 0]);
    line(to = [20, 10]);
    line(to = [5, 10]);
}
// Ctrl+Z, Ctrl+Z, Ctrl+Shift+Z
linear_extrude(2) sketch(closed = false) {
    start([0, 0]);
    line(to = [20, 0]);
    line(to = [20, 10]);
}
  • undo reverts exactly one action
  • redo restores it

Z13 Dragging a handle

In drawing mode the view shows the handles of all segments of the sketch. Dragging uses the existing handle logic: on a grid point the reference is rewritten, literals are changed (Alt: numbers).

grid g {
    x: a = 0, b = 10, c = 30;
    y: u = 0, v = 15;
}
linear_extrude(2) sketch {
    start(g[a, u]);
    line(to = g[c, u]);
    line(to = g[c, v]);
    close();
}
  • g[b, v] → g[c, v]

Z14 Deleting a segment

With the Select tool, a click on a segment puts the cursor on its line, Del (or "Delete") removes the statement. The only segment of a contour takes the contour with it, as does a corner() directly after it.

linear_extrude(2) sketch {
    start([0, 0]);
    line(to = [30, 0]);
    line(to = [0, 20]);
    close();
}
  • line(to = [30, 20]) removed

}

Z15 Sketch under transformation, rotate_extrude

The sketch plane comes from the engine (OpInfo.Sketch.plane): under transformations its node coordinate system, in rotate_extrude the xz plane in which the profile lies in the body, in centered linear_extrude its bottom face. Camera, grid, snap and handles use the same plane; the values remain sketch coordinates.

translate([0, 0, 10]) rotate([90, 0, 0]) linear_extrude(3) sketch {
    start([0, 0]);
    line(to = [20, 0]);
    line(to = [20, 10]);
    line(to = [10, 15]);
    close();
}

rotate_extrude() sketch {
    start([10, 0]);
    line(to = [20, 0]);
    line(to = [20, 5]);
    line(to = [15, 8]);
    close();
}
  • view y = 1.00000
  • snap point z = 20 (world)
  • rotate_extrude: view y = 1.00000

11 Limitations

  • Main file only: in another project file the mode does not start; sketches from included files are not a target.
  • Statements in loops or modules are not deleted, and their corner does not get a corner() (message). The drawing state in the middle of a loop is the one after its last iteration.
  • Snap only to the sketch, visible grids and anchors – not to body edges or other sketches; horizontal/vertical only relative to the previous point.
  • Bézier only cubic, no spline tool; line(by = …) and length + angle are not generated (except tangent line(length = …)).
  • A new sketch is a bare 2D sketch (to get a body: e.g. write linear_extrude in front of it).
  • The camera keeps the orbit control's "z up": in rotated planes the sketch's y axis is not necessarily vertical on screen. With a drawing tool the left mouse button does not rotate the camera (right pans, wheel zooms, "Select" to rotate).
  • Tauri: T16 operates the view with synthetic pointer events.
