# Test reports

Each report is a `report.html` (images in `img/` or in the folder) and a `report.pdf`. The
reports are snapshots: numbers and limits apply to the stated commit. The generators are in
`tools/report/` (their output is German; the reports in this folder were translated to English
afterwards). Intermediate results of the test runs go to `reports/tmp/` (not checked in). The
PDF is printed with `node tools/report/print-pdf.mjs <report.html> <report.pdf> [footer title]`
using Playwright's Chromium (`cd tools/report && npm i playwright@1.56.1 --no-save`).
Screenshots show the UI and CLI output as they were at the time, i.e. in German.
Not a test report, but generated the same way: the catalogue of example models
[`docs/models/everyday-models.pdf`](../models/everyday-models.pdf) (`tools/report/katalog.mjs`, see [`docs/models/README.md`](../models/README.md)).

Requirements of the generators (local): SMLib sources (`smlib/fetch.sh`), natively built
libraries (`SMLIB_PREBUILT`), emsdk 6.0.13, wasm-bindgen-cli in the version from
`Cargo.lock`, OpenSCAD 2021.01 (reports 1, 6), a venv with `cadquery-ocp==8.0.1.1.0`
(reports 5–7, 21), Python 3 with Pillow (reports 8 and 22, pixel counting), Chromium from Playwright 1.56.1, for reports 9, 11, 18, 19, 20 and 21 the Tauri packages, Xvfb, WebKitWebDriver (`webkit2gtk-driver`), `tauri-driver` 2.1.0 and ImageMagick (`scripts/ci/desktop.sh deps e2e-deps`), for report 11 a venv with `lib3mf` and `trimesh` as well as PrusaSlicer (apt, optional; report 17: G-code of the stencil). The reports do not run in CI; the
checks they are based on do (`.github/workflows/`).
