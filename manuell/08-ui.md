# mcad ui

The UI watches the open files: edits by the agent (file writes, `mcad set`) appear immediately
if the user has no unsaved changes in that file; otherwise the UI asks the user (reload /
keep mine / compare) and overwrites nothing.

| Command | Result |
| --- | --- |
| `mcad ui status [--json]` | per window: `project`, `dirty` (unsaved files), `cursor`, `selection`, `context` module, `params` (parameter bar), `diagnostics`, `scene`, `section` (as `mcad render` args in `section.cli`) |
| `mcad ui show FILE [--line N] [--module M]` | open/switch to the file, set the cursor, raise the window |
| `mcad ui screenshot -o x.png` | the user's 3D view |

Without a running UI: exit 3 – continue headless.

Files in the UI: "New" ("Neu"), "Save as" ("Speichern unter") and a new folder project create `.mcad`; open dialogs,
folders (all model files), drag & drop and upload take `.mcad` and `.scad`. Window title
`<file> – mcad`; desktop app id `dev.mcad.desktop` (Wayland `app_id`, X11 `WM_CLASS`, desktop
file `dev.mcad.desktop.desktop` for `text/x-mcad` and `application/x-openscad`).

While the engine loads or evaluates, a spinner sits under the camera bar (top right of the 3D
view; tooltip: progress and line). Long models are fine: only a single kernel call without an
answer for 20 min counts as hung ("Engine not responding for 20 min (kernel hangs)" / "Engine
reagiert seit 20 min nicht (Kernel hängt)"); the engine restarts and that node is blocked until
its line changes. `MCAD_WATCHDOG_MS` overrides.

Asserts (`mcad usage asserts`): keep-out volumes hatched yellow with a dashed outline, toggle
"Keep-out volumes" ("Sperrvolumen") in the view toolbar (remembered), not pickable or measurable; violations red
(intersection body), contact faces green, gaps as dimension lines with labels. A click on
"n assert violations" ("n Assert-Verletzungen") in the status bar or on the warning at the line
end jumps to the statement and frames the violation; every export asks "Export anyway" ("Trotzdem
exportieren", = `--ignore-asserts`).

Kernel errors with a place (operands of a Boolean touching tangentially): contact edges red,
a red point at the place; the message at the line end is a link (tooltip "Click: show the
place in the view") that frames the place.

Before writing a file: if it is in `dirty`, ask the user. Use `mcad ui show` to point the user
at a line you changed.

## UI language

Settings (gear icon, top right) → "Language" ("Sprache"):

| Choice | UI language |
| --- | --- |
| System (default) | `navigator.language` starting with `de` → German, else English |
| English | English |
| Deutsch | German |

Kept per browser / desktop webview (localStorage `cad-lang`: `system`, `en`, `de`), switches
without reload, sets `<html lang>`. Only the UI is translated: diagnostics, measurement texts,
sketch prompts and other engine messages, `mcad` CLI output and the examples stay German.
Shortcuts: English shows "Ctrl+S" / "Del", German "Strg+S" / "Entf".
