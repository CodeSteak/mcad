# cad ui

The UI watches the open files: edits by the agent (file writes, `cad set`) appear immediately
if the user has no unsaved changes in that file; otherwise the UI asks the user (reload /
keep mine / compare) and overwrites nothing.

| Command | Result |
| --- | --- |
| `cad ui status [--json]` | per window: `project`, `dirty` (unsaved files), `cursor`, `selection`, `context` module, `params` (parameter bar), `diagnostics`, `scene`, `section` (as `cad render` args in `section.cli`) |
| `cad ui show FILE [--line N] [--module M]` | open/switch to the file, set the cursor, raise the window |
| `cad ui screenshot -o x.png` | the user's 3D view |

Without a running UI: exit 3 – continue headless.

While the engine loads or evaluates, a spinner sits under the camera bar (top right of the 3D
view; tooltip: progress and line). Long models are fine: only a single kernel call without an
answer for 20 min counts as hung ("Engine reagiert seit 20 min nicht (Kernel hängt)"); the
engine restarts and that node is blocked until its line changes. `CAD_WATCHDOG_MS` overrides.

Before writing a file: if it is in `dirty`, ask the user. Use `cad ui show` to point the user
at a line you changed.
